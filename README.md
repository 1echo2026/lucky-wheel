# lucky-wheel · 宠粉日幸运大转盘

纯前端抽奖活动页：**内置问卷 → 大转盘抽奖 → 中奖图文弹窗**，配套隐藏管理后台维护奖品与活动配置。

- 线上地址：https://1echo2026.github.io/lucky-wheel/
- 管理后台：https://1echo2026.github.io/lucky-wheel/admin.html （默认密码 `admin888`，进入后请修改）

## 视觉风格（国潮喜庆红金）

朱红为底、赤金为饰、宣纸为卡；标题与按钮用宋体（`STZhongsong / Songti SC / SimSun`），正文用黑体。两个页面共用同一套设计令牌（CSS 变量写在各自 `<style>` 顶部，值保持一致）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--red-600/700/800/900` | `#B3121B / #8E0F18 / #6E0910 / #4E0509` | 页面底、题头、转盘格、印章 |
| `--gold-200/400/500` | `#FFE9A8 / #E9C468 / #D2A544` | 金环、按钮、描边、深底上的文字 |
| `--gold-ink` | `#8A5F16` | 宣纸卡片上的金色文字（保证 4.5:1 对比度） |
| `--paper / --paper-2` | `#FFF9F0 / #FDF1DF` | 宣纸卡片、输入框底 |
| `--ink / --ink-soft` | `#3A1A12 / #80604F` | 正文、次要说明 |

细节：金环跑马灯铆钉（抽奖时点亮）、如意水滴指针、印章式中奖弹窗（金光扫过 + 金粒/花瓣）、云纹底纹（低透明度 SVG data URI）、卡片描金双线（外框 + 内嵌发丝线）。动效遵循 `prefers-reduced-motion`：减少动效时转盘瞬停、不撒金粒、不做滚动动画。

## 功能

**用户参与页（index.html）**
- 参与前填写内置问卷（姓名 / 基地 / 出单手机号 / **工号（必填）**，字段可开关）
- 手机号必须为 11 位数字，否则弹窗提示「请检查您输入的手机号是否有误」
- 一个出单手机号只能抽一次奖；同一工号可对应多个出单手机号（工号不参与唯一性校验）
- 大转盘：格数随奖品数自动变化（最多 10 格），奖格文字沿半径排布；按配置概率加权抽奖，库存抽完自动移出
- 抽奖动效：5 圈减速旋转 + 指针抖动 + 金环跑马灯闪烁 + 中奖格闪光，约 4.4 秒后弹出结果
- 中奖弹窗：印章「恭喜中奖」+ 奖品图文轮播（每奖品最多 5 张图）；结果名称含「谢谢参与 / 未中奖 / 再来一次」时印章切换为「再来」，且不撒金粒
- 顶部显示期数、抽奖开始时间与**抽奖截止时间**，到点自动截止并禁止参与
- **抽奖记录**：按「期数 · 奖池」分组展示，格式如 `宠粉日第 88 期 · 进阶奖池` + `抽奖时间，奖项奖品`；历史各期记录全部保留
- 支持自定义活动背景图（背景图单独一层，叠加暗红蒙版，保证红金氛围与文字可读）

**管理后台（admin.html）**
- 与活动页共用同一套国潮红金令牌（暗红题头 + 宣纸卡片 + 描金按钮 + 红底金字表头），风格与前台一致
- 密码门进入（默认 `admin888`，可修改）
- **抽奖模板选择**：下拉切换前台抽奖外观，选完即在下方实时预览（用当前奖品渲染），保存设置后前台生效
- 奖品管理：新增/删除/编辑，名称、概率、库存，每奖品上传最多 5 张图（第 1 张为主图），图片自动压缩存本机
- 活动设置：**期数名称、奖池名称**、抽奖开始/截止时间、每人次数、问卷开关与字段、基地选项
- **活动背景图（所有人可见）**：上传后在后台一键发布到仓库 `assets/bg.jpg`，所有访客打开抽奖页都能看到；也可直接填图片链接
- **抽奖记录查询**：按出单手机号或工号模糊查询，可按期数筛选，结果含 期数 / 奖池 / 抽奖时间 / 出单手机号 / 姓名 / 基地 / 工号 / 奖品奖项
- 数据工具：导出中奖记录 JSON、导出活动配置 JSON、清空记录

## 抽奖模板（可扩展）

抽奖外观集中在 `templates.js` 的模板注册表里，前台按 `config.template` 加载，后台下拉可切换。

**内置模板**

| id | 名称 | 说明 |
|---|---|---|
| `wheel-bing` | 大转盘 · 丙 高对比 | 双强红交替 + 粗白分隔 + 大号如意指针（默认） |
| `wheel-jia` | 大转盘 · 甲 浓烈红 | 深浅红四色交替 + 细金分隔（原国潮样式） |
| `wheel-yi` | 大转盘 · 乙 简金 | 宣纸底 + 淡朱红 + 细金线，雅致款 |
| `grid-red` | 九宫格 · 国潮 | 8 格跑马灯 + 中心抽奖按钮 |

**模板接口**（新增一个玩法只需加一个对象）

```js
{
  id: 'wheel-x',                 // 唯一标识，写入 config.template
  name: '大转盘 · XX',            // 后台下拉显示名
  slots: 10,                     // 最多展示几个奖品（页面只从这里挑奖，保证“看得见 = 抽得到”）
  render(root, prizes) {},       // 渲染舞台，内部需产出抽奖按钮 .lw-spin-btn
  spin(root, index, onDone) {}   // 播放落点动画并高亮中奖格，结束后回调 onDone()
}
```

模板自带样式（注入 `<style id="lw-template-style">`）与渐变定义（`#lwGold` / `#lwPointer`），因此后台预览无需页面样式即可正确显示。
概率加权、库存扣减、记录写入都在页面侧（`pickPrize` 等），换模板不影响这些逻辑。

## 背景图如何让所有人看到

抽奖页按以下优先级加载背景：

1. 仓库里的 `assets/bg.jpg`（后台「上传并发布背景图」产生）→ **所有访客可见**
2. 后台填写的图片链接 → **所有访客可见**
3. 本机上传的旧背景图 → 仅本机可见（历史兼容）

**发布背景图需要一次性配置**：后台「活动背景图」处填入一个 GitHub 令牌（需对该仓库有 Contents 写入权限）并点保存，令牌只存在本机浏览器、不会上传到任何地方。发布后约 1~10 分钟全网生效（GitHub Pages 缓存）。

> 如果本机网络无法访问 `api.github.com`（hosts 被改等情况），发布按钮会提示失败，此时可改用「图片链接」方式：把图片传到任意可公开访问的地址后粘贴链接。
> 奖品图片仍只存本机，如需所有人可见请改把奖品图用于背景/链接方式，或后续接入后端。

## 数据存储（全部在本机浏览器）

| 数据 | 位置 |
|---|---|
| 活动配置 | localStorage `lw_config` |
| 中奖记录 | localStorage `lw_records`（含 期数 / 奖池 / 抽奖时间 字段） |
| 奖品图片、旧背景图 | IndexedDB `lucky_wheel` → `images`（`<奖品id>::<序号>`、`bg::0`） |
| 管理密码 | localStorage `lw_pass` |
| GitHub 令牌与仓库 | localStorage `lw_gh_token` / `lw_gh_repo` |

> 配置与记录保存在「当前浏览器」中，换设备/换浏览器需重新配置，或用后台的「导出活动配置」备份。
> 中奖记录导出字段：期数 / 奖池 / 手机号 / 姓名 / 基地 / 工号 / 奖品 / 抽奖时间，与中奖名单审核工具口径对齐，后续可直接导入审核。
