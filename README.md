# lucky-wheel · 宠粉日幸运大转盘

纯前端抽奖活动页：**内置问卷 → 大转盘抽奖 → 中奖图文弹窗**，配套隐藏管理后台维护奖品与活动配置。

- 线上地址：https://1echo2026.github.io/lucky-wheel/
- 管理后台：https://1echo2026.github.io/lucky-wheel/admin.html （默认密码 `admin888`，进入后请修改）

## 功能

**用户参与页（index.html）**
- 参与前填写内置问卷（姓名 / 基地 / 出单手机号 / **工号（必填）**，字段可开关）
- 手机号必须为 11 位数字，否则弹窗提示「请检查您输入的手机号是否有误」
- 一个出单手机号只能抽一次奖；同一工号可对应多个出单手机号（工号不参与唯一性校验）
- 大转盘：格数随奖品数自动变化（最多 10 格），按配置概率加权抽奖，库存抽完自动移出
- 中奖弹窗：奖品图文轮播（每奖品最多 5 张图）
- 顶部显示抽奖开始时间与**抽奖截止时间**，到点自动截止并禁止参与
- **抽奖记录**：按「期数 · 奖池」分组展示，格式如 `宠粉日第 88 期 · 进阶奖池` + `抽奖时间，奖项奖品`；历史各期记录全部保留
- 支持自定义活动背景图

**管理后台（admin.html）**
- 密码门进入（默认 `admin888`，可修改）
- 奖品管理：新增/删除/编辑，名称、概率、库存，每奖品上传最多 5 张图（第 1 张为主图），图片自动压缩存本机
- 活动设置：**期数名称、奖池名称**、抽奖开始/截止时间、每人次数、问卷开关与字段、基地选项
- **活动背景图**：可上传本机背景图，或填图片链接（链接方式所有访客可见）
- 数据工具：查看中奖记录、导出中奖记录 JSON、导出活动配置 JSON、清空记录

## 关于背景图与图片的两种生效范围

| 方式 | 生效范围 |
|---|---|
| 后台「上传背景图」/ 上传奖品图片 | 只存在本机浏览器，仅本机可见 |
| 后台「背景图链接」填图片 URL | 所有访客可见（图片需先托管到可公开访问的地址） |

## 数据存储（全部在本机浏览器）

| 数据 | 位置 |
|---|---|
| 活动配置 | localStorage `lw_config` |
| 中奖记录 | localStorage `lw_records`（含 期数 / 奖池 / 抽奖时间 字段） |
| 奖品图片、背景图 | IndexedDB `lucky_wheel` → `images`（`<奖品id>::<序号>`、`bg::0`） |
| 管理密码 | localStorage `lw_pass` |

> 配置与图片保存在「当前浏览器」中，换设备/换浏览器需重新配置，或用后台的「导出活动配置」备份。
> 中奖记录导出字段：期数 / 奖池 / 手机号 / 姓名 / 基地 / 工号 / 奖品 / 抽奖时间，与中奖名单审核工具口径对齐，后续可直接导入审核。

## 部署

纯静态页面，推到 GitHub 后由 GitHub Pages 直接托管（根目录即站点）。本地双击 `index.html` 也可直接使用。
